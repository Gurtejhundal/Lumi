# Asset and License Rules

Coucou's code is MIT-licensed, but its brand/character/media have separate restrictions.

For this project:

## Allowed direction
- learn from interaction patterns
- reuse MIT-licensed code only with required notices
- independently implement similar categories of behavior
- use our own geometry, art, sounds and naming

## Do not copy
- Coucou name
- Mochi character design
- icon
- sound files
- screenshots/media as product assets
- protected branding

## Our original identity
- working project name: Nox Island
- character: Nox
- silhouette: rounded manta/comet
- eye design: narrow luminous capsules
- motion system: independently specified in this repository

Before shipping publicly, run a license review of every third-party dependency and asset.
