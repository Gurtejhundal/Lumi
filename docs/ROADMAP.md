# Roadmap

## Phase 0 — Lock visual prototype
Goal: get the visual language right before system integration.

Deliver:
- Nox idle animation
- hover response
- compact island
- expanded island
- working state
- permission state
- success state
- file-drop state

Exit criterion:
Animations feel intentional at 60 fps and no state looks like a generic toast.
