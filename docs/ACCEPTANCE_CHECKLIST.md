# Acceptance Checklist

## Visual
- [ ] Island aligns perfectly to screen top-center.
- [ ] No visible native window frame.
- [ ] No accidental grey rectangle around transparency.
- [ ] Compact island is not taller than needed.
- [ ] Expanded island has consistent spacing.
- [ ] Nox reads clearly at 1x and 2x scaling.
- [ ] Nox is visibly distinct from Mochi.

## Motion
- [ ] No animation stutters during normal desktop use.
- [ ] Hover does not instantly explode into a large panel.
- [ ] Entry and exit animations are asymmetric and natural.
- [ ] Character blink timing is non-mechanical.
- [ ] Gaze movement is smooth and bounded.
- [ ] Success animation finishes quickly.
- [ ] Repeated events do not restart animations chaotically.
- [ ] Reduced-motion mode exists.

## Desktop behavior
- [ ] Passive island does not steal focus.
- [ ] Click-through works outside visible surface.
- [ ] Fullscreen behavior is configurable.
- [ ] Multi-monitor placement is correct.
- [ ] Works after GNOME login/autostart.
- [ ] Survives display scale changes.

## Codex
- [ ] Session start appears.
- [ ] File edits appear.
- [ ] Commands appear.
- [ ] Permission request blocks auto-hide.
- [ ] Allow/Deny maps to correct request.
- [ ] Completion state appears.
- [ ] No fake progress percentage.

## System
- [ ] Volume HUD.
- [ ] Brightness HUD where supported.
- [ ] Bluetooth connect/disconnect.
- [ ] Battery state.
- [ ] MPRIS media.
- [ ] Network state.
